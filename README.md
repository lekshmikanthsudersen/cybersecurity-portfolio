# Cybersecurity portfolio

Portfolio of Sudersen Lekshmikanth, a security operations analyst studying WQE7001 Cyber Security at Universiti Malaya. It presents an isolated virtual lab, a scoped service scan, and a reflection on what the evidence supports.

[Open the live portfolio site](https://lekshmikanthsudersen.github.io/cybersecurity-portfolio/)

## Projects

- [Private virtual lab setup](projects/virtual-lab-setup/README.md): VMware network setup, isolation checks and [saved route output](projects/virtual-lab-setup/evidence/route-check.txt).
- [Scoped Nmap service scan](projects/nmap-service-scan/README.md): a four-port scan of one owned target, with [saved scan output](projects/nmap-service-scan/evidence/scan-output.txt).

The lab used two owned virtual machines on a private VMware LAN segment. Published evidence is limited to lab addresses, selected screenshots and short output excerpts. No employer or client data is included.
