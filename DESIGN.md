# Portfolio design

## Purpose

Present Sudersen Lekshmikanth's security operations work to a lecturer and a professional reader. The two lab records and their original evidence should be easy to find, read and verify.

## Direction: case workspace

The site is organised as a read-only analyst workspace. The explorer lists the assignment sections and case files. Open tabs lead to the overview, each project and the evidence record. A narrow status bar shows only facts supported by the published lab work. The real Nmap screenshot appears in the first view.

The interface takes visual cues from [Nitin Ranganath's MIT-licensed VSCode Portfolio](https://github.com/itsnitinr/vscode-portfolio). Other visual references are [Playground MacOS](https://github.com/Renovamen/playground-macos) and [Shaqdeff Portfolio](https://github.com/shaqdeff/Portfolio-Template). This site uses its own static HTML and CSS. No reference code, images or icons were copied.

## Visual system

- Canvas #15191F, editor #20252D, explorer #1B2027.
- Main text #E8EDF2, muted text #ABB8C5, rules #343D48.
- Accent #EFAA77 for the active file and key action, mint #8FD4C4 for links and role text.
- System sans serif for prose and headings. Consolas or Cascadia Code for interface labels, code and evidence captions.
- Reading columns stay near 70 characters. Long sections use generous line spacing and clear rules.
- The 54-pixel activity rail, 228-pixel explorer and editor form the desktop workspace. The explorer and then the rail disappear as the viewport narrows. Mobile keeps ordinary navigation and horizontal document tabs.

## Content and interaction

- The seven required portfolio sections remain on the overview page, with their checked word counts.
- The two project URLs, original evidence files, hashes and factual qualifications remain unchanged.
- File labels and tabs are working links. The source and evidence links remain accessible without JavaScript.
- Mobile evidence tables use labelled rows so hashes and scan results remain readable.
- The planned CompTIA CySA+ credential remains clearly unearned.
